## 🛰️ Проект 1: Прогнозирование риска столкновений на низкой околоземной орбите

**Сфера:** Классическое машинное обучение, анализ временных рядов, работа с несбалансированными данными

### Постановка задачи
Прогнозирование риска столкновения космических аппаратов с объектами космического мусора на низкой околоземной орбите (НОО). Основная сложность — работа с реальными, сильно несбалансированными данными, где события с высоким риском составляют всего ~6%.

### Используемые данные
- Реальные данные от Европейского Космического Агентства (ESA)
- Временные ряды сообщений об опасных сближениях (CDM) за 2015-2019 гг.
- 162634 строк/CDM, сгруппированных в 13154 события
- 103 параметра на каждый CDM

### Реализованные модели

#### Классификация (бинарная, порог -6 для high-risk)
| Модель | F2-score |
|--------|----------|
| Базовое решение (Naive) | 0.385 |
| Алгоритм команды `sesc` | **0.410** |
| CatBoost | 0.125 |

#### Регрессия (предсказание точного значения риска)
| Модель | RMSE |
|--------|------|
| Базовое решение (Naive) | 9.422 |
| Random Forest | 9.254 |
| XGBoost | 8.842 |
| CatBoost | 8.576 |
| Алгоритм команды `sesc` | 8.160 |
| **LightGBM** | **7.445** |

### Ключевые особенности реализации
- **Стратифицированное разделение данных** с сохранением структуры событий
- **Обработка несбалансированности** через веса классов
- **Создание признаков** с использованием лагов (lag features) для учета временной динамики
- **Реализация эвристического алгоритма** команды-победителя соревнования ESA

### Метрики оценки
- **F2-score** для классификации (β=2, приоритет на полноту)
- **RMSE** для регрессии

### Результаты
Алгоритм `sesc` показал наилучший результат в задаче классификации (F2-score = 0.410), а `LightGBM` — в задаче регрессии (RMSE = 7.445), что подтверждает эффективность градиентного бустинга для данного типа данных.

## 🌍 Проект 2: Увеличение разрешения аэрокосмических снимков с использованием диффузионных моделей

**Сфера:** Computer Vision, генеративные модели (Diffusion Models), обработка изображений

### Постановка задачи
Повышение пространственного разрешения (Super-Resolution) аэрокосмических снимков с коэффициентом 4 (увеличение с 64×64 до 256×256 пикселей) с использованием условной диффузионной модели.

### Используемые данные
- Датасет **UC Merced Land Use**
- 2100 изображений, 21 семантический класс (сельскохозяйственные угодья, леса, городские застройки, водоемы и др.)
- Формат RGB, размер 256×256 пикселей
- Разделение: 90% train (1890 изображений), 10% val (210 изображений)

### Архитектура модели SR3

#### Формализация диффузионного процесса
- **Прямой процесс:** постепенное добавление гауссовского шума к HR-изображению
  $$q(x_t | x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t} x_{t-1}, \beta_t I)$$
- **Обратный процесс:** итеративное восстановление из шума с условием на LR-изображение
- **Обучение:** предсказание добавленного шума $\epsilon_\theta(x_t, t, y)$

#### Структура U-Net
- **Residual blocks** с GroupNorm и активацией SiLU
- **Skip-connections** для сохранения пространственной информации
- **Временной эмбеддинг** через синусоидальные позиционные кодировки
- **Условная передача LR** через конкатенацию на входе

### Обучение
| Параметр | Значение |
|----------|----------|
| Количество шагов диффузии (T) | 1000 |
| Эпохи | 220 |
| Оптимизатор | Adam |
| Learning rate | 2e-4 |
| Функция потерь | MSE между предсказанным и реальным шумом |

### Метрика оценки
**LPIPS** (Learned Perceptual Image Patch Similarity) — метрика, коррелирующая с человеческим восприятием

### Результаты
| Метод | LPIPS (↓ лучше) |
|-------|-----------------|
| Бикубическая интерполяция | 0.4197 |
| **SR3 (диффузионная модель)** | **0.137** |

### Визуальные результаты
Диффузионная модель превосходит классическую интерполяцию, восстанавливая четкие границы и текстурные детали (очертания дорог, зданий, границы полей), критически важные для аэрокосмических снимков.

## 🧾 Проект 4: Разработка системы поиска информации по биографиям спортсменов (NLP)

**Сфера:** Natural Language Processing, Information Retrieval, RAG (Retrieval-Augmented Generation)

### Постановка задачи
Разработка поисковой системы для ответов на вопросы о биографиях спортсменов. Основные задачи:
- Извлечение структурированной информации из текстов Wikipedia
- Построение эффективного поискового индекса (TF-IDF, BM25, эмбеддинги E5)
- Ранжирование результатов поиска (pairwise reranking)
- Генерация ответов с использованием LLM (Qwen3-0.6B)
- Оценка качества работы системы (Recall@k, DCG, LLM-as-a-judge)

### Используемые данные
- **Корпус документов:** 110 статей о пловцах из русской Wikipedia
- **Вопросно-ответные пары:** 638 пар (вопрос — правильная статья)
- **Дополнительный корпус:** 110 статей о баскетболистах для расширения датасета

### Реализованные модели и подходы

#### Базовые поисковые модели
| Модель | Recall@1 | Recall@5 | DCG@5 |
|--------|----------|----------|-------|
| TF-IDF (только текст) | 0.8715 | 0.9577 | 0.9505 |
| TF-IDF (только заголовок) | 0.6505 | 0.6708 | 0.6710 |
| **TF-IDF (заголовок + текст)** | **0.8887** | **0.9624** | **0.9554** |

#### Эмбеддинг-модели (multilingual-e5-base)
| Модель | Recall@1 | Recall@5 | DCG@5 |
|--------|----------|----------|-------|
| E5-base (без дообучения) | 0.8417 | 0.9420 | 0.9291 |
| E5 + MNRL (Multiple Negatives Ranking Loss) | **0.9483** | **0.9890** | **0.9716** |
| E5 + ContrastiveLoss (3 негатива) | 0.8621 | 0.9828 | 0.9262 |

#### Переранжирование (Logistic Regression + ручные признаки)
| Этап | Recall@1 | Recall@5 | DCG@5 |
|------|----------|----------|-------|
| TF-IDF (базовый retrieval) | 0.8887 | 0.9624 | 0.9554 |
| **TF-IDF + reranking** | **0.9859** | **1.0000** | **0.9948** |

### Генерация ответов с использованием LLM (Qwen3-0.6B)

#### Сравнение подходов
| Метод | Accuracy (LLM-as-a-judge) |
|-------|---------------------------|
| Без RAG | 0.5909 |
| RAG (1 документ, TF-IDF retrieval) | 0.6191 |
| RAG (5 документов, TF-IDF retrieval) | 0.5674 |
| **RAG (1 документ, reranking)** | **0.7800** |
| **RAG (5 документов, reranking)** | **0.8000** |

### Ключевые особенности реализации

#### 1. Обработка текста
- Приведение к нижнему регистру
- Токенизация по словам
- Нормализация знаков препинания

#### 2. Поисковые модели
- **TF-IDF:** с объединением заголовка и текста
- **BM25:** для дополнительного ранжирования
- **E5:** многоязычная эмбеддинг-модель с дообучением

#### 3. Дообучение эмбеддингов
- **MNRL (Multiple Negatives Ranking Loss):** эффективное обучение без явных негативов
- **ContrastiveLoss:** обучение на триплетах (query, positive, negative)

#### 4. Переранжирование
Ручные признаки для логистической регрессии:
- Косинусное сходство (E5)
- Совпадение имени спортсмена
- Совпадение чисел (годы, дистанции)
- TF-IDF сходство
- BM25 скор
- Категориальное совпадение (стиль плавания, страна)

#### 5. Оценка качества
- **LLM-as-a-judge:** автоматическая оценка ответов LLM
- **Cohen's Kappa:** согласованность с человеческой оценкой
- **Recall@k и DCG:** для оценки поиска

### Результаты и выводы

1. **Наилучшие результаты поиска** достигнуты комбинацией:
   - TF-IDF retrieval (20 кандидатов)
   - Ручные признаки + Logistic Regression (reranking)

2. **Дообучение эмбеддингов** (MNRL) улучшает качество поиска на 10% по Recall@1.

3. **Качество генерации LLM** значительно улучшается при использовании релевантных документов:
   - RAG с 1 документом (reranking) даёт прирост +19% по сравнению с генерацией без RAG
   - RAG с 5 документами (reranking) даёт прирост +21%

4. **LLM-as-a-judge** показал умеренное согласование с человеческой оценкой (Kappa ≈ 0.06), что требует дополнительной настройки промптов.

## 📊 Проект 5: Анализ тональности отзывов о заведениях Москвы

**Сфера:** Natural Language Processing, анализ тональности (Sentiment Analysis), дообучение BERT-моделей

### Постановка задачи
Создание модели для автоматического определения тональности (положительной, отрицательной или нейтральной) отзывов пользователей о заведениях (рестораны, кафе, парки, отели, компании и т.д.) в районе метро Бауманская в Москве. Цель — автоматизировать сбор и анализ обратной связи для бизнеса и городских сервисов.

### Используемые данные
- **Датасет:** Собственный датасет, собранный из открытых источников (например, Яндекс.Карты).
- **Структура:** 514 размеченных отзывов.
- **Метки тональности:**
  - `0` — отрицательная (негативный отзыв)
  - `1` — нейтральная (фактическое сообщение без яркой эмоциональной окраски)
  - `2` — положительная (позитивный отзыв)

### Реализованные подходы и модели

#### 1. Бейслайн модель (без обучения)
- **Модель:** ruBERT (DeepPavlov/rubert-base-cased) без дообучения.
- **Метод:** Классификация на основе эмбеддингов.
- **Результат:** Accuracy **0.296** — неудовлетворительный результат, подтверждающий необходимость дообучения на целевой предметной области.

#### 2. Дообучение модели ruBERT
- **Модель:** ruBERT (DeepPavlov/rubert-base-cased).
- **Метод:** Полное дообучение (fine-tuning) на датасете отзывов.
- **Результат:** Accuracy **0.685**. Значительный прирост качества после дообучения.

#### 3. Дообучение с использованием `catboost` и ручных признаков
- **Метод:** Комбинированный подход: эмбеддинги из дообученного ruBERT (усредненные по словам) подаются на вход модели CatBoost.
- **Итоговая модель:** Ансамбль из **CatBoost + дообученный ruBERT**.
- **Результат:** Accuracy **0.833**. Это наилучший результат, показывающий, что комбинация глубоких и "ручных" признаков эффективна для такой задачи.

### Метрика оценки
- **Accuracy** — доля правильно классифицированных отзывов. Выбор обоснован сбалансированностью классов в датасете.

### Результаты и выводы

| Модель | Accuracy |
|--------|----------|
| Бейслайн (ruBERT без обучения) | 0.296 |
| Дообученный ruBERT | 0.685 |
| **CatBoost + дообученный ruBERT** | **0.833** |

1.  **Дообучение на целевых данных критически важно:** Бейслайн на эмбеддингах ruBERT без дообучения работает на уровне случайного угадывания (0.296). Дообучение модели на датасете отзывов повысило точность до 0.685.
2.  **Ансамбль CatBoost и дообученного BERT дал наилучший результат:** Комбинация мощного языкового представления (ruBERT) и дополнительных ручных признаков (которые могут включать длину отзыва, количество восклицательных знаков и т.д.) позволила достичь точности 0.833, что на 14.8% выше, чем у одного дообученного ruBERT. Это подчеркивает ценность гибридных подходов в NLP.
3.  **Качество модели достаточное для практического применения:** Модель с точностью 83.3% может эффективно использоваться для автоматической первичной классификации отзывов, значительно сокращая время ручного анализа.

## 📈 Проект 6: Анализ и прогнозирование временных рядов

**Сфера:** Эконометрика, анализ временных рядов, статистическое моделирование, прогнозирование

### Постановка задачи
Построение вероятностной модели для экономического временного ряда. Основные задачи: проверка стационарности, идентификация детерминированной и случайной составляющих, выбор адекватной модели ARMA, диагностика остатков и построение прогноза на один шаг вперед. Проект демонстрирует классический подход к моделированию временных рядов, применяемый в экономике, финансах и других областях.

### Используемые данные
- **Ряд:** Непрерывный временной ряд (условный экономический показатель)
- **Объем:** 200 наблюдений
- **Источник:** Сгенерированные данные, имитирующие структуру экономического ряда

### Реализованные этапы и модели

#### 1. Проверка на единичный корень (процедура Доладо-Дженкинса-Сосвилла-Риверо)
- **Цель:** Определить, является ли ряд стационарным относительно тренда (TSP) или имеет единичный корень (DSP).
- **Модель:** Регрессия вида $\Delta X_t = \alpha + \beta \cdot t + \gamma \cdot X_{t-1} + \delta_1 \cdot \Delta X_{t-1} + \varepsilon_t$.
- **Результат:** Оценка коэффициента $\hat{\gamma} = -1.359$ со стандартной ошибкой $0.125$ и t-статистикой $-10.906$. Рассчитанное значение $(\hat{\gamma}-1)/se = -18.93$ оказалось меньше критического значения $-3.41$, что привело к **отвержению гипотезы о единичном корне (H₀: γ = 1)**. Ряд был признан **стационарным около тренда (TSP)**.

#### 2. Оценка детерминированной составляющей
- **Модель:** Линейный тренд $\mu_t = \beta_0 + \beta_1 \cdot t$.
- **Результат оценки:** $\hat{\mu}_t = 9.3384 + 12.0813 \cdot t$. Коэффициент тренда статистически значим (p-value < 0.05), константа — нет. Средний прирост ряда за период составил 12.08.

#### 3. Детрендирование
- **Действие:** Вычитание оцененного тренда из исходного ряда: $u_t = X_t - \hat{\mu}_t$.
- **Результат:** Получен стационарный случайный процесс $u_t$, среднее значение которого близко к нулю.

#### 4. Идентификация случайной составляющей
- **Метод:** Анализ автокорреляционной (ACF) и частной автокорреляционной (PACF) функций детрендированного ряда $u_t$.
- **Вывод:** На основе анализа коррелограмм были выбраны две кандидатные модели: AR(1) и AR(2).

#### 5. Оценка параметров моделей
| Модель | Оценка параметров | σ² |
|--------|-------------------|-----|
| **AR(1)** | $\hat{\phi}_1 = -0.5120^{***}$ | 1.0000 |
| **AR(2)** | $\hat{\phi}_1 = -0.4594^{***},\ \hat{\phi}_2 = 0.1021$ | 1.0000 |

*Примечание:* $^{***}$ — значимость на уровне 0.001.

#### 6. Выбор модели по информационным критериям
| Модель | AIC | BIC |
|--------|-----|-----|
| AR(1) | 2324.16 | **2334.05** |
| AR(2) | **2324.05** | 2337.24 |

- **Вывод:** По критерию BIC, который более строг к переобучению, была выбрана модель **AR(1)**.

#### 7. Диагностика остатков (для модели AR(1))
- **Среднее:** 0.036 (незначимо отличается от нуля)
- **Тест Льюнга-Бокса на автокорреляцию:** p-value = 0.3692 → автокорреляция остатков отсутствует.
- **Тест Харке-Бера на нормальность:** p-value = 0.7429 → распределение остатков не отличается от нормального.
- **Вывод:** Модель AR(1) адекватно описывает данные.

#### 8. Прогноз на один шаг
- **Прогноз детерминированной составляющей:** $\hat{\mu}_{201} = 2437.69$
- **Прогноз случайной составляющей:** $\hat{u}_{201} = -49.26$
- **Итоговый прогноз:** $\hat{X}_{201} = 2388.42$
- **95% доверительный интервал:** $[2232.61, 2544.23]$

### Ключевые особенности реализации
- **Статистическая проверка гипотез:** ADF-тест с модифицированной регрессией для проверки на единичный корень.
- **Построение тренда:** МНК-оценка линейного тренда.
- **Анализ стационарности:** Визуальный и формальный анализ коррелограмм.
- **Оценка ARMA-моделей:** Использование `statsmodels` (ARIMA).
- **Выбор модели:** Сравнение по критериям AIC и BIC.
- **Диагностика:** Проверка остатков на автокорреляцию (тест Льюнга-Бокса) и нормальность (тест Харке-Бера).
- **Прогнозирование:** Точечный и интервальный прогноз.

### Результаты и выводы
1.  **Ряд является стационарным около тренда (TSP):** Тест на единичный корень не выявил наличия единичного корня, что позволяет строить модель на основе детрендированного ряда.
2.  **Выбрана адекватная модель AR(1):** Среди рассмотренных кандидатов модель AR(1) показала наилучшие результаты по критерию BIC и успешно прошла диагностику остатков.
3.  **Построен прогноз:** Получен точечный и интервальный прогноз значения ряда на следующий период. Это демонстрирует возможность использования построенной модели для предсказания будущих значений.
4.  **Подтверждена применимость классического подхода:** Проект демонстрирует эффективность классической методологии анализа временных рядов (от проверки стационарности до построения прогноза) для практических задач.

## 📊 Итоговые выводы

1.  **Для табличных данных с временной структурой** градиентный бустинг (LightGBM) и эвристические алгоритмы показали наилучшие результаты, особенно при работе с сильно несбалансированными выборками.
2.  **Для задач генерации изображений** диффузионные модели значительно превосходят классические методы интерполяции, обеспечивая визуально правдоподобное восстановление деталей.
3.  **Для задач поиска информации** комбинация TF-IDF retrieval и обученного reranker даёт практически идеальные результаты (Recall@5 = 1.0).
4.  **RAG (Retrieval-Augmented Generation)** значительно улучшает качество ответов LLM (+21% accuracy), особенно при использовании высококачественного retrieval (reranking).
5.  **Для анализа тональности** дообучение BERT-моделей на специфичных данных повышает точность с 0.296 до 0.685, а гибридный подход с CatBoost и ручными признаками позволяет достичь 0.833, что подтверждает эффективность комбинации глубоких и классических методов.
6.  **Для классического анализа временных рядов** методология, включающая проверку на единичный корень, построение тренда, идентификацию и оценку ARMA-моделей, а также диагностику остатков, позволяет построить адекватную прогнозную модель. В рамках проекта была выбрана модель AR(1), которая успешно прошла все этапы верификации.
7.  **Все проекты** демонстрируют практическое применение ML в аэрокосмической отрасли, городской аналитике и смежных областях — от предотвращения столкновений спутников до улучшения качества спутниковых снимков, интеллектуального поиска информации, автоматического анализа обратной связи и прогнозирования экономических показателей.
